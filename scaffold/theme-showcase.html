Overview

Avery Chen teaches interactive graphics, leads a systems lab, and develops courseware for visualization, observability, and performance storytelling. This page is intentionally broad enough to show how the themes affect typography, spacing, hierarchy, data views, forms, and code.

The implementation emphasizes keyboard focus, high contrast, modern semantic structure, and theme switching that follows explicit user choice while still supporting system dark mode by default.
